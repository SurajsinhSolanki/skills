## Finding

**P2: Blank rename overwrites valid stored profile instead of rejecting.** At app/profile.py:5-7, `rename` assigns input without validation. Starting from `Profile('Ada')`, each of `''`, `' '`, `'\t'`, `'\n'`, and `' \t\n '` was accepted without an exception and replaced `profile.name`. README.md:5-6 requires `ValueError` and unchanged stored name. This is a verified pre-existing implementation defect; no fix was authorized or applied. A correction should validate before assigning, while preserving valid input exactly. The stored regression test currently checks only a valid return value and misses both blank rejection and stored state preservation.

**FAIL — ephemeral profile contract audit (exit 1), pre-existing implementation defect:**

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -B - <<'PY'
import unittest
from app.profile import Profile

class ProfileContractAudit(unittest.TestCase):
    def test_valid_names_preserve_return_and_state(self):
        for name in ('Grace', '  Grace  ', 'Zoë 李', 'A' * 10000):
            with self.subTest(name=name if len(name) < 50 else '10000 characters'):
                profile = Profile('Ada')
                self.assertEqual(profile.rename(name), name)
                self.assertEqual(profile.name, name)

    def test_blank_names_reject_and_preserve_state(self):
        for name in ('', ' ', '\t', '\n', ' \t\n '):
            with self.subTest(name=repr(name)):
                profile = Profile('Ada')
                try:
                    profile.rename(name)
                except Exception as error:
                    outcome = type(error).__name__
                else:
                    outcome = 'accepted'
                self.assertEqual((outcome, profile.name), ('ValueError', 'Ada'))

    def test_repeated_valid_updates_preserve_latest_name(self):
        profile = Profile('Ada')
        for name in ('Grace', 'Grace', 'Zoë'):
            self.assertEqual(profile.rename(name), name)
            self.assertEqual(profile.name, name)

unittest.main(verbosity=2)
PY
```

Every blank subtest failed with actual `('accepted', <blank input>)` against expected `('ValueError', 'Ada')`. Counts are 3 methods and 5 failing subtests, not 5 separately counted test methods. The exception is converted to an explicit observed outcome so both error and stored state are checked together; unexpected exception types also fail.
