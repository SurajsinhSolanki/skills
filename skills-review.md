# Skill instruction review

> **Fixes applied:** The reviewed issues have been addressed in the installed skills. See [implementation and validation](skill-fixes/fixes-applied.md). The findings below describe the earlier versions.

Reviewed 27 October 2026.

This is a static review of the **23 skills advertised in this chat**, plus **21 additional entrypoints** found in the configured skill roots: 20 cached artifact templates and one review helper. I examined routing, operational constraints, conflicting instructions, resource references and maintenance risks. Large entrypoints received targeted inspection of those areas. This is not an exhaustive audit of every supporting script, reference, generated artifact or live integration. Orca's version-served guides were not executed or validated. Temporary plugin trees outside the configured roots are excluded.

No installed skill was edited. `imagegen` and `openai-docs` changed on disk during the review; findings for those two use the later re-read versions. The companion inventory records the final observed entrypoint hashes. During this review, the cached review-agent helper disappeared and a plugin-creator system skill appeared. The newly appearing plugin-creator was not part of the advertised list and was not reviewed; the inventory is therefore not an immutable snapshot of all reviewed content.

## Fix first

1. **Restore codebase-knowledge's missing package contents.** Its required `references/knowledge-spec.md`, `scripts/quick_validate.py` and `scripts/visualize.py` do not exist. The installed directory contains only `SKILL.md`. The documented workflows cannot be completed as written.
2. **Remove accidental configuration changes from documentation lookup.** The latest openai-docs instructions automatically add a missing MCP server and ask for a restart, even when official browsing could answer the question.
3. **Reconcile imagegen with the live tool.** The latest skill denies the existence of a native transparency control, but this session explicitly exposes `transparent_background`. It unnecessarily routes work into local chroma removal and potentially a different API model.
4. **Protect human edits in generated knowledge.** Keeping an AUTO-GENERATED marker after editing is normal. The marker alone is not evidence that overwriting is safe. Compare against the prior generated content before replacing it.
5. **Remove contradictions and blanket rules.** Validation must not silently write; requested CSV output must not become XLSX; host communication requirements must win; typography preferences should not invalidate legitimate content.

## Maintenance approach

- Keep the entrypoint focused on selection, essential invariants and completion. Move lengthy examples and mode-specific procedures into references.
- Share workbook guidance between standalone and live Excel skills instead of maintaining two large copies.
- Check packaged resources at installation time. Exclude illustrative paths inside examples from broken-reference reports.
- Include realistic positive and negative trigger examples for overlapping skills, especially Sites versus repository work and Orca versus native coordination.
- Define bounded recovery and resumable checkpoints for expensive generation or rendering workflows.
- Separate mandatory tool/runtime contracts from defaults and aesthetic preferences.
- Apply changes to user-maintained sources or upstream packages. Changes made only to versioned plugin caches may disappear when those packages are replaced.

Start with the missing codebase-knowledge resources and the imagegen/openai-docs conflicts. Then fix output-format and read-only contradictions. Reduce duplication and soften style preferences after the correctness issues are resolved.
